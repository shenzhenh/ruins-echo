## 4. 已知问题 / 技术债

1. **双生回响能量与池容量**：池只剩 1 个位置时仍扣 2 倍能量，召唤 1 个。建议 M4 决定“退还差额”或“预留池位”。
2. **回放使用绝对世界坐标**：跨房间召唤会回到录制房间的坐标。规格如此，但正式房间流程需要决定“同房间限制”或“坐标重定位”。
3. **敌人死亡使用 Destroy**：未走对象池；M2 接入。
4. **IMGUI 非最终 UI**：正式 UI 在 M5；当前 HUD 只用于技术验证。
5. **无场景 / Prefab**：首次打开需手动生成 Main 场景（或直接 Play 空场景）。
6. **`.meta` 为手写**：首次 Unity 导入可能补充 importer 字段；不要改 GUID。
7. **暴击 / 标记数值为补充规则**：规格未给具体数值，已集中到 `GameConfig`，便于调整。
8. **玩家攻击无前摇动画**：只有时间逻辑；命中在 0.15s 后结算。
9. **Boss 反向回放未接线**：`ShadowEcho.SetPlaybackDirection` 已提供，等 Boss 调用。
10. **无暂停**：ESC 尚未实现；`Time.timeScale = 0` 时影子仍按 Unscaled 回放，需要暂停时显式停 `isPlaying`。
